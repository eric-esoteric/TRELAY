# TRELAY Android — политика конфиденциальности

Дата: 22 сентября 2026 года.

TRELAY направляет сетевой трафик только выбранных пользователем приложений через настроенные им VPN-серверы. Остальные приложения используют обычное подключение. TRELAY не содержит рекламы или аналитических SDK и не продаёт пользовательские данные.

## Что обрабатывается

- Список установленных приложений читается на устройстве, чтобы пользователь мог выбрать приложения для каждого маршрута. TRELAY не загружает этот список разработчику.
- Маршруты, серверы, ключи и настройки сохраняются в приватном хранилище приложения, зашифрованном ключом Android Keystore. При работе движка конфигурация может временно находиться в приватных файлах приложения; эти файлы удаляются после запуска движка или при следующем старте VPN.
- Журнал движка хранится на устройстве. Он содержит время, состояние маршрутов, проверок и ошибок, иногда имена маршрутов, адреса соединений и технические сведения. Ключи и пароли намеренно не записываются. Журнал можно посмотреть, очистить или отправить вручную через кнопку «Поделиться» в настройках. Журнал автоматически ротируется по размеру.
- При использовании HTTPS-подписки запрос отправляется выбранному пользователем провайдеру. Некоторые подписки требуют случайный идентификатор клиента, а также версию ОС, модель устройства и язык; эти сведения передаются провайдеру подписки. Его правила обработки данных определяются им самим.
- При использовании ссылок `key://` выполняется DNS-over-HTTPS-запрос к Cloudflare для поиска сервиса конфигурации; запрос может содержать идентификатор заказа из ссылки. Сервис конфигурации получает запрос, необходимый для выдачи VPN-конфигурации.
- Проверки доступности могут обращаться к Cloudflare, Google и адресам, настроенным в маршрутах. Сетевой трафик выбранных приложений поступает к выбранному VPN-провайдеру и далее к запрошенным ими сервисам. Провайдер и конечные сервисы могут видеть данные соединений согласно своим правилам.

TRELAY не расшифровывает содержимое защищённых HTTPS-соединений приложений. Android показывает системное разрешение перед первым включением VPN; без согласия VPN не запускается.

## Управление данными

Маршруты и журнал остаются на устройстве, пока пользователь их не изменит, не очистит журнал или не удалит данные приложения. Для удаления всех локальных данных можно очистить хранилище TRELAY в настройках Android или удалить приложение. Данные, уже переданные VPN-провайдеру, сервису подписки либо другим внешним сервисам, регулируются их собственными политиками.

По вопросам политики можно написать в [Issues проекта TRELAY](https://github.com/eric-esoteric/TRELAY/issues).
