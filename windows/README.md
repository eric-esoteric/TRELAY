# TRELAY for Windows

Portable-версия TRELAY для Windows 10/11 x64.

1. Распакуйте ZIP целиком в отдельную папку.
2. Запустите `TRELAY.exe`.
3. При первом включении маршрутизации разрешите установку системного компонента.

Папка `engine` обязательна: в ней находятся Xray, Mihomo и ProxiFyre. Не запускайте один `TRELAY.exe` отдельно от остальных файлов архива.

Профили и ключи не хранятся рядом с программой. Они защищаются учётной записью Windows и сохраняются в `%LOCALAPPDATA%\TRELAY`.
