# TRELAY Beta 0.3

Единый beta-релиз Windows и Android.

## В релизе

- Windows x64 portable ZIP со встроенными Xray, Mihomo и ProxiFyre.
- Android ARM64 APK с выборочным VPN для приложений.
- Единое название и версия `Beta 0.3` в интерфейсе и метаданных.
- Android-интеграция с TLINE для передачи состояния маршрута и быстрой SIP-перерегистрации после failover.
- Ключи и пользовательские конфиги исключены из репозитория и релизных пакетов.

## Проверено

- Windows: Release-сборка без ошибок, корректные метаданные, полный portable-пакет и изолированный snapshot-запуск.
- Android: debug и release-сборки, ARM64 ABI, package ID `com.trelay.android`, версия `0.3-beta`, APK Signature Scheme v3.
- Подпись Android совпадает с ранее выпущенной Beta 0.3, поэтому обновление сохраняет совместимость.

## Перед рабочим использованием

Проверьте на целевом устройстве регистрацию SIP, входящий и исходящий звонок, звук в обе стороны, переход на резерв и возврат после сна устройства.
